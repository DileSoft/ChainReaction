# Цепная реакция

**🎮 Играть: [dilesoft.github.io/ChainReaction](https://dilesoft.github.io/ChainReaction/)**

Браузерный симулятор производственных цепочек. Vite + TypeScript, без сторонних библиотек и игровых движков.

## Механика

Вы расставляете заводы на сетке 9×9. Соседние заводы (по вертикали и горизонтали) соединяются автоматически: каждый завод сам тянет нужное сырьё у соседей и складывает продукцию на выход.

У каждого завода есть шкала **стабильности**:

* **Голод** — не хватает сырья, стабильность падает.
* **Переизбыток** — склад выхода переполнен, продукцию никто не забирает, стабильность падает ещё быстрее.
* На нуле стабильности завод **взрывается** и исчезает навсегда.

## Производственная цепочка

```
Руда → Слиток → Пластина → Каркас  ┐
              └→ Шестерня ─────────┴→ Модуль
```

Пропорции важны: Сварке нужно 2 пластины за такт, Сборке — 1 каркас и 2 шестерни.

**Склад** покупает пластины, **Порт** — модули. Это ваш доход.

## Уровни

Кампания из 30 уровней, пять актов по шесть, прогресс сохраняется в браузере.
Выбор уровня — кнопка «Ур. N» в шапке или клавиша `M`; открывается следующий, если пройден предыдущий.

| Акт | Что осваивает |
| --- | --- |
| I. Основы | постройка, цепочка, переизбыток и нехватка |
| II. Ветвление | шестерни, каркасы, модули, пропорции |
| III. Замкнутый цикл | конечные залежи и Рециклер |
| IV. Ограничения | стены, жёсткий бюджет, таймер |
| V. Мастерство | разделение потоков, запрет сноса, большие цели |

Звёзды за уровень: ★ — пройдено, ★★ — без единого взрыва, ★★★ — ещё и в норматив времени.

### Здания

Помимо производственных заводов есть **приёмки** — они покупают ресурс и ничего не производят:
Скупщик руды, Скупщик слитков, Скупщик шестерён, Скупщик каркасов, Склад (пластины) и Порт (модули).
Чем глубже переработка, тем дороже ресурс за единицу руды.

**Рециклер** забирает слиток и возвращает в шахту 2 единицы руды — так замыкается цикл на уровнях с конечным рудником.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc --noEmit + vite build → dist/
npm run preview  # посмотреть production-сборку
```

В dev-режиме в консоли доступны два хелпера:

- `__game` — живая модель текущего уровня;
- `__verify()` — прогоняет все 30 уровней по эталонным застройкам из `src/game/levels/refs.ts` и возвращает таблицу «пройден/провал, такты, взрывы». Помогает не сломать баланс при правке цифр.

### Редактор уровней

Открывается в dev-сборке: кнопка **«Редактор»** на карте уровней или адрес `http://localhost:5173/?editor=1`.

- Паспорт уровня: id, название, подзаголовок, бриф, цель, стартовый капитал, норматив, лимит времени, запрет сноса.
- Палитра: галочками выбираются доступные постройки, порядок галочек = клавиши `1–9`.
- Поле 9×9: один клик ставит одно здание, режимы «Стена» и «Стереть»; правый клик стирает клетку.
- У каждой предустановки можно задать залежи (`deposit`) и множитель выпуска (`rate`).
- Снизу — готовый JSON и кнопки «Скопировать JSON», «Скачать объект», «Скачать акт», «Играть». Черновик автоматически сохраняется в `localStorage`.
- «Играть» запускает черновик поверх игры: прогресс не пишется, а на экране победы/поражения можно вернуться в редактор.

Кампания хранится не в коде, а в JSON-файлах `src/game/levels/act1…act5.json`. «Скачать акт» отдаёт весь файл акта с уже заменённым уровнем — достаточно положить его поверх старого. Можно и скопировать один объект и вставить его в массив вручную. Подсказка под заголовком показывает, в какой акт попадёт уровень по его `id`; для id за пределами 30 нужно добавить новый акт и диапазон в `ACTS`.

```json
// src/game/levels/act1.json
[
  {
    "id": 31,
    "name": "Новый цех"
  }
]
```

Файлы читаются при сборке через `import … from './actN.json'`; `index.ts` проверяет структуру и падает с понятной ошибкой, если в JSON неизвестная постройка, координаты вне поля 9×9, пустое название или повторяющийся `id`.

## Структура

```
src/
  main.ts              точка входа: собирает Game + Renderer + App
  style.css            оформление
  game/
    data.ts            ресурсы, рецепты, стоимость, здания и типы уровней
    types.ts           типы зданий, событий и инструментов
    Game.ts            чистая модель: сетка, такты, экономика, взрывы, уровни
    Renderer.ts        отрисовка canvas, эффекты, попадание по клетке
    Sound.ts           синтез звуков на WebAudio
    levels/            кампания: act1…act5.json, сборочный index и refs для автопроверки
  dev/
    verify.ts          прогон эталонных застроек по всем уровням
    levelEditor.ts     визуальный редактор уровней и экспорт JSON
  ui/
    App.ts             DOM: шапка, палитра, подсказки, модальные окна, цикл
    LevelMap.ts        карта кампании
    progress.ts        сохранение прогресса и звёзд в localStorage
```

`Game` ничего не знает про DOM: он только меняет состояние и шлёт типизированные события (`transfer`, `explode`, `income`, `toast`, `win`, `gameover`). `Renderer` превращает их в анимации, `App` — в интерфейс.
